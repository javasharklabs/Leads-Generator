# Leads Generator Extension by JavaShark

A powerful Chrome extension to extract business leads from Google Maps and Justdial and export them into CSV format for lead generation, marketing, outreach, and business automation workflows.

Built for marketers, agencies, freelancers, startups, and growing businesses.

---

# 🚀 Features

## Business Lead Extraction
Easily collect business data from:
- Google Maps
- Justdial

Search anything like:
- Restaurants in New Delhi
- Gyms in Mumbai
- Salons in Gurgaon
- Real Estate Agents
- Doctors
- Cafes
- Digital Marketing Agencies
- Hotels
- Repair Services

Simply scroll through listings and generate leads instantly.

---

# 📊 CSV Export Includes

The extension automatically extracts:

- Business Name
- Phone Number
- Address
- Website
- Ratings (if available)
- Business Category

Export all leads into a clean CSV file.

---

# ⚡ How It Works

1. Open Google Maps or Justdial
2. Search for any business category
3. Scroll down to load more businesses
4. Open the extension
5. Click **Generate CSV**
6. Leads will automatically download as a CSV file

---

# 🔧 How to Install

## Step 1 — Download
Download the ZIP file from this release.

## Step 2 — Extract
Extract the ZIP file to any folder.

## Step 3 — Open Chrome Extensions
Open Chrome and go to:

```txt
chrome://extensions/
```

## Step 4 — Enable Developer Mode
Turn ON **Developer Mode** from the top-right corner.

## Step 5 — Load Extension
Click **Load Unpacked** and select the extracted extension folder.

Done ✅
