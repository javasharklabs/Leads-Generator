# Leads Generator Extension

A simple Chrome extension to extract business leads from Google Maps and Justdial.

## Features
- Search any business category like:
  - Restaurants in New Delhi
  - Gyms in Mumbai
  - Salons in Gurgaon
- Scroll through the business listings
- Click the "Generate" button in the extension
- Automatically export leads as a CSV file

## CSV Includes
- Business Name
- Phone Number
- Address
- Website (if available)

## How to Install

1. Download the ZIP file from this release
2. Extract the ZIP file
3. Open Chrome browser
4. Go to:
   chrome://extensions/
5. Enable "Developer Mode"
6. Click "Load Unpacked"
7. Select the extracted extension folder

## How to Use

1. Open Google Maps or Justdial
2. Search for any business
   Example:
   - restaurants in delhi
   - gyms in gurgaon
3. Scroll down to load more results
4. Open the extension
5. Click "Generate CSV"
6. CSV file will download automatically

## Lead Manager Import

You can import the generated CSV file into:

[https://javashark.in/tools/lead-manager](https://javashark.in/tools/lead-manager)

to manage and organize your leads.
